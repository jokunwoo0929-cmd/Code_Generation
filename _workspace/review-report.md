## 1. 코드 개요

`factorial(int n)` 함수를 구현한 C 프로그램으로, 사용자로부터 정수를 입력받아 팩토리얼 값을 출력한다.

---

## 2. 규칙별 검사 결과

### 규칙 A: 반복문(for/while) 사용 여부 (재귀 금지)

- 판정: **준수**
- 근거:
  - `factorial` 함수 내에서 자기 자신을 호출하는 재귀 호출이 전혀 없다.
  - `for` 반복문을 사용하여 누적 곱셈으로 팩토리얼을 계산하고 있다.

준수 코드 (9~12번 줄):
```c
int result = 1;
for (int i = 2; i <= n; i++) {
    result *= i;
}
```

### 규칙 B: 음수 입력에 대한 예외 처리 여부

- 판정: **준수**
- 근거:
  - 함수 진입부(6번 줄)에서 `n < 0` 조건을 검사한다.
  - 음수 입력 시 즉시 에러값 `-1`을 반환한다.
  - `main` 함수에서도 반환값 `-1`을 감지하여 에러 메시지를 출력하는 처리가 구현되어 있다.

준수 코드 (6번 줄 및 22~24번 줄):
```c
// factorial 함수 내
if (n < 0) return -1;

// main 함수 내
if (result == -1) {
    printf("오류: 음수 입력은 허용되지 않습니다.\n");
}
```
